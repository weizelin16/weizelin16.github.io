# README
>很早以前就萌生了要把所有的文章记录下来的想法，尽管零碎的句子片段并没有太大的价值，但记录了当时我的所思所想，记录了我的生活，这便是我的生活，这便是“我之所以称为我”的原因。

以上是三四年前第一次写网站时留下来的话，写作之于我像个朋友，定期写下文章之后才意识到自己思想转变之快，也因为写作的原因对生活有了更加深刻的体悟。但仍不希望被过度解读，也不希望被很多人看到。写在这里，也算是个标签。如果有人愿意了解我的话，我直接发一个网站，人们便能循着我的路径了解我。

**第一，我对中国哲学、国学有着极深的兴趣。**从2024年3月开始写了一些公众号文章，本意是探索自我，另一方面算是对过去的一些总结和一些心得体会。文章写得晦涩，不擅长叙事，大多只是悬浮在空中的直观感受，不愿迎合读者、不图流量，只是不断剖析内心，力图证得自我。所以读者不多，目前也只有五百多个。在这个过程当中接触佛、道，读了不少国学经典，在思想上有了极大提升。如果有兴趣的话也欢迎关注，公众号名字叫：Lichtr。

**第二，我非常喜欢音乐，几乎没有一天不听音乐。**过去的十年里弹吉他，今年开始学钢琴，不求神速，只是慢慢学习弹一些曲子，以表达自己的心情。只是随着对国学、佛、道的理解，很多过去喜欢的歌不再喜欢，只喜欢听写简单的、纯粹的音乐，不再爱听那些浓烈的情感。抖音上有我弹的曲子的一些视频：Lichtr。

**第三，我是一个理想主义者，对生活有着绝对纯粹的追求。**这种追求完全来自于内心，而不被外物所缚。我喜欢简单的生活，喜欢秩序。所以不太喜欢和人利益交换、尔虞我诈，只愿和心地纯粹之人做些纯粹的事。

另外，在这里记录一下自己的进步，不要辜负苍天之厚。
